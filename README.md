# ERU AI · 비트코인 리스크 가드

[운영 앱 열기](https://eru-ai-investment-simulator.vercel.app)

**스플래시 → 이메일 전용 설정 → 투자금 입력 → 비트코인 세 사이클 자동 비교 → 자산·낙폭 결과 → 대응 복기**를 제공하는 모의 시뮬레이터입니다.

모바일은 고정 하단 탭과 화면별 주요 버튼, 가로로 넘기는 복기 장면으로 구성합니다. 기본 언어는 영어이며 **Settings → 한국어** 또는 상단 **EN** 버튼에서 전환합니다. 영어는 싱가포르 달러(SGD, S$), 한국어는 원화(KRW, ₩)로 입력·표시합니다. 투자금·차트·결과·복기·기록과 결과 메일에 같은 기준을 적용합니다. 언어 선택은 이 기기에 저장되고 기존 비교·기록과 수익률은 유지됩니다.

새로 접속했을 때 기본 투자금은 영어 **S$100,000**, 한국어 **1억 원**입니다. 금액을 직접 수정하기 전에는 언어에 맞는 기본값으로 전환하며, 직접 입력하거나 빠른 금액을 선택한 뒤에는 같은 원금을 환산 표시합니다. 새 비교의 입력 금액과 이전 비교의 원금은 분리하여 기존 기록을 복원해도 새 기본값이나 작성 중인 금액을 덮어쓰지 않습니다.

표시 환산율은 [ECB 2026-11-13 기준환율](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html)의 EUR/KRW 1477.80과 EUR/SGD 1.4236을 교차 계산한 **S$1 ≈ 1,038.07원**으로 고정합니다. 실제 환전이나 과거 환율 수익을 계산하지 않습니다. SGD는 소수 둘째 자리로 입력하며 원화 기준 장부에는 센트 환산 후 Decimal 금액을 전달합니다. 기존 원금을 환산 표시한 채 그대로 제출하면 표시 반올림으로 원금이 바뀌지 않습니다.

앱 화면은 기기의 높이에 맞춰 고정하고 콘텐츠만 내부에서 스크롤합니다. 첫 화면은 투자금과 재생을 조작하는 대시보드이며, 데스크톱에서도 같은 모바일 화면 구성을 유지합니다. 스플래시는 원본 로고로 제작한 4.8초 MP4를 접속·새로고침 시 재생합니다. 이전 탭의 시청 여부로 생략하지 않습니다. 설정의 다시 보기 메뉴는 제공하지 않습니다. 자동 재생 제한이나 영상 오류 때는 로고 화면을 표시한 뒤 진입하고, 모션 감소 설정에서는 정적인 인트로를 표시합니다.

- 두 계좌 모두 같은 자금으로 비트코인 100%에서 출발합니다. 단순 보유와 가드의 분할 매도·대기·재매수를 비교합니다.
- 기간은 2016.07~2020.04, 2020.05~2023.06, 2023.07~2026.05이며 각 구간은 독립적으로 시작합니다. 기본 입력 자금 1억 원, 총 기본 재생 300초, 배속과 결과 바로 보기를 지원합니다.
- Coinbase Exchange의 공식 BTC-USD 일봉 3,683개를 검증했습니다. 엑셀의 규칙을 서버의 Decimal 장부로 재계산하며, 판단 이후 다음 일봉 시가에 체결합니다.
- 원화 자본에 USD 가격 변동률을 적용한 비교입니다. 수수료 0.05%를 반영하며 환율 변동·현금 이자·슬리피지는 미반영합니다.
- 낙폭이 줄어도 최종 자산이 단순 보유보다 적을 수 있습니다. 최대 낙폭과 종료 손익을 함께 표시하며, 혼합 포트폴리오 리플렛의 수치를 BTC 단독 성과로 사용하지 않습니다.
- 기록은 이 브라우저의 방문자 쿠키로 구분해 서버에 보관합니다. 다른 기기에 자동 연결되지 않습니다. 진행 중 미래 시세와 대응을 공개하지 않습니다.

## 결과 메일

처음 접속하면 스플래시 다음에 이메일 전용 화면을 표시합니다. 이메일과 결과·회사 소개 수신 동의를 저장한 뒤 별도 투자금 설정 화면으로 넘어갑니다. 투자금 화면에는 이메일 입력을 섞지 않습니다. 설정의 **보고서 수신 설정 → 수신 이메일 변경**에서 새 주소와 동의를 저장할 수 있습니다. 인증번호는 받지 않습니다. 비교가 끝나면 서버가 실제 종료 결과와 ERUTY 회사 소개를 Resend로 자동 발송합니다. 자동 재생 완료와 결과 바로 보기 모두 같은 발송 경로를 사용합니다. 본문에는 세 사이클의 자산 변화 그래프, 종료 자산·최대 낙폭, 시간·대응 종류로 고른 대표 매도·대기·재매수 장면을 넣습니다. 앱과 같은 어두운 배경과 금빛 강조를 사용하며, 상세 결과·전체 복기 PDF와 회사 소개 PDF를 함께 첨부합니다. 상세 복기에는 주요 장면 전체와 전체 모의 대응 내역을 담습니다. 영어는 SGD, 한국어는 KRW 보고서를 보냅니다.

운영 환경은 Resend에서 인증된 `eruty.co.kr` 도메인의 `ERU AI RiskGuard <noreply@eruty.co.kr>`를 발신 주소로 사용합니다. `RESEND_API_KEY`와 `RESEND_FROM_EMAIL`은 서버의 Vercel Production 환경에만 등록하며, 변경 후에는 운영 배포를 다시 실행해야 합니다. 같은 결과·수신자·보고서 버전에 대한 중복 요청은 재발송하지 않습니다. 이전 기본 메일을 받은 경우 새 상세 보고서 버전(`review-2`)을 한 번 요청할 수 있습니다. 이미지 그래프는 외부 주소로 공개하지 않고 메일 내부 CID 첨부로 전달합니다. 수신 주소·동의는 방문자 쿠키에 연결된 서버의 이메일 설정으로 보관합니다. 새 비교는 저장된 설정을 사용하며, 보고서 언어는 각 비교를 시작할 때 정합니다. 브라우저 저장소에는 이메일을 저장하지 않습니다. 공개 응답에는 마스킹한 주소와 발송 상태만 제공합니다. 발송 접수 후 해당 결과의 원문 이메일은 제거하고, 이후 비교에 사용할 이메일 설정은 유지합니다. 변경한 주소는 새 비교와 아직 발송하지 않은 보고서부터 적용합니다. 이미 발송했거나 발송 처리 중인 보고서는 기존 주소를 유지하여 중복 발송을 막습니다. 결과 화면에서는 자동 발송 상태를 확인하고, 실패한 경우에만 등록한 주소로 재시도할 수 있습니다. 이미 발송된 보고서는 새로고침으로 중복 발송하지 않습니다. 이전 이메일 미등록 기록의 결과·복기는 유지되며, 새로운 이메일 설정은 첫 접속 시 한 번 등록하고 이후 이 브라우저에서 재사용합니다. 자동 보고서는 새 비교부터 적용합니다. 화면의 ‘발송 접수’는 공급자 접수 상태이며 받은편지함 배달 완료와 구분합니다.

## 개발·검증

프론트엔드 의존성과 빌드는 로컬 캐시를 사용하는 `scripts/BUILD.ps1`로 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/BUILD.ps1
& "$env:LOCALAPPDATA\ERU-AI\alpha-v1-venv\Scripts\python.exe" -m pytest tests -q
Push-Location archive/ERU_AI_Investment_Simulator_V2
& "$env:LOCALAPPDATA\ERU-AI\alpha-v1-venv\Scripts\python.exe" -m unittest discover -s tests -v
Pop-Location
```

데이터·계산·공개 경계·메일 상태·배포 원본 보관은 [비트코인 자동 비교 V1 구현 기록](docs/비트코인_자동비교_V1.md)을 확인하세요. 시세 원본·정규화 CSV·DB·인증정보는 커밋하지 않습니다.

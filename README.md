# ERU · AI 동행 투자 V3

실제 과거 시세로 **자산 이해 → 포트폴리오 구성 → 초기 자동 매매 → 가드와 논의 → 승인한 매매 실행**을 경험하는 5분 투자 시뮬레이션입니다. 초기 자금은 **1억 원**, 거래 대상은 가명 코인 4종과 현금 (이자 수익)입니다.

## 바로 실행

**[온라인에서 AI 동행 투자 테스트하기 →](https://eru-ai-investment-simulator.vercel.app)**

이미 투자 중이라면 [새 초기 설정부터 테스트하기](https://eru-ai-investment-simulator.vercel.app/?setup=1)로 새 게임을 시작할 수 있습니다. 기존 게임은 삭제하지 않습니다.

1. 처음부터 AI와 상담하며 **안정형·균형형·공격형** 성향과 현금·투자 배분을 함께 정합니다. AI 제안을 초안에 담거나 직접 선택할 수 있습니다.
2. 먼저 **현금 (이자 수익)·투자**로 자금을 나눈 뒤, **투자금 안에서 가명 코인 4종을 직접 선택하고 비중을 설정**합니다. 안전 성향은 현금 비중에 반영합니다.
3. **리스크 조건 상담**에서 AI와 종목 손실·하루 하락·쏠림·전체 손실 알림을 정합니다. 제안을 초안에 담고 수정한 뒤, 비중·주문 예산·현금 이자와 리스크 조건을 함께 확인하고 `이 구성으로 투자 시작 → 확정하고 자동 투자 시작`을 누릅니다.
4. 초기 주문은 **판단 이후 다음 일봉 시가**에 체결됩니다. 내 포트폴리오에서 실제 수량·비중·손익과 누적 이자를 확인합니다.
5. 가드가 시장을 멈추면 근거와 대응을 논의합니다. 유지·종목 매수/매도·전체 비중 조정 중 선택하고, 변경 내용을 확인한 뒤 승인합니다.
6. 승인한 주문만 자동 실행됩니다. 판단 기록에 선택과 실제 체결 가격·수량·수수료가 연결됩니다.
7. 활성 재생 300초 후 매매 순손익과 이자를 분리해 확인하고, 처음 계획과 마지막 구성을 비교하거나 새 계획으로 재도전합니다.

**AI 연결:** 서버의 `OPENROUTER_API_KEY`로 OpenRouter Chat Completions API를 호출합니다. 기본 모델은 `openai/gpt-6-luna`이며 서버의 `OPENROUTER_MODEL`로 변경할 수 있습니다. 구조화 출력 지원 제공업체로만 요청하며 OpenAI 직접 연결이나 Vercel AI Gateway로 자동 우회하지 않습니다. 초기 설정 화면에서 대화창을 바로 사용할 수 있고, 단계별 고정 안내와 실제 AI 답변을 구분합니다. 각 답변에 실제 연결 또는 규칙 기반 대체 안내의 이유를 표시합니다.

AI는 성향·현금/투자 비중·선택 종목·리스크 조건 초안·설정 단계·최근 대화 12개와 현재 공개 사실을 바탕으로 자연스러운 설명과 비중 초안을 제시합니다. 설명과 제안을 서버에서 검증하고 별도 근거 검토를 거칩니다. 실제 식별자·URL·미래 사건과 미확정 시세는 공개하지 않습니다. 질문이나 초안 적용만으로 주문하지 않습니다. 자세한 설정은 [OpenRouter 대화 연결](docs/OpenRouter_대화_연결.md)을 확인하세요.

초기 상담에서 성향·현금 비중을 먼저 제안받고, 종목과 별도로 리스크 알림 조건도 만들 수 있습니다. 예: **“새벽코인은 매수원가보다 8% 하락하면 알려줘.”** 조건을 초안에 담고 시작할 때 함께 승인하면 해당 조건 도달 시 시장을 멈추고 대응을 논의합니다. [초기 AI 상담과 리스크 조건](docs/AI_초기상담과_리스크조건.md)

종목 이름은 **새벽코인·물결코인·산들코인·노을코인**입니다. **자산 살펴보기 → 종목 선택**에서 거래별 체결가·수량·금액·수수료·매도 실현손익과 누적 손익을 확인할 수 있습니다. [가명과 종목별 거래 내역](docs/가명과_종목별_거래내역.md)

## 게임·체결 규칙

- 기간: **2022-11-07 00:00 KST~2026-08-05 23:59:59 KST**, 활성 재생 300초. 준비·대화·정지 중에는 게임 시간이 흐르지 않습니다.
- 초기 자금 100,000,000원에서 확정한 비중에 따라 초기 주문을 일괄 접수합니다. 대기 자금 100% 구성도 가능합니다.
- 서버가 시간·시세·수수료·잔고를 계산하고 Decimal 장부로 저장합니다.
- 매수 예산은 **수수료 포함 총지출 한도**, 매도 비율은 **보유 수량 기준**입니다. 매수·매도 수수료는 각각 0.05%입니다.
- 승인한 주문은 다음 일봉 시가에서 체결하므로 예상 수량·수령액과 다를 수 있습니다. 비중 조정은 매도 후 실제 확보한 자금 범위에서 매수합니다.
- 한 번에 하나의 주문 묶음을 접수하며 체결 전에 취소할 수 있습니다. 주문 예약금과 주문 가능 금액을 구분합니다.
- 대기 자금 이자는 과거 한국은행 기준금리 연동 **교육용 모델**이며 실제 예금 상품 금리가 아닙니다. 변경일 다음 날부터 적용하고 게임 경과 기간에 세전 단리로 적립해 종료 시 정산합니다. 주문 예약금과 미수이자에는 이자를 붙이지 않습니다.
- 예금·적금·채권의 차이를 안내하지만 미확정 E/F/G를 거래 상품으로 추가하지 않습니다. 주식·부동산 준비 중 화면과 새 투자 자료 공개 알림은 제외했습니다.
- 실제 식별자·원문 URL·미래 이벤트·미확정 일봉은 종료 전에 브라우저로 보내지 않습니다. 차트에는 완료된 일봉만 표시합니다.
- 장기 연결 중단은 게임 날짜를 건너뛰지 않도록 정지합니다. V2의 기존 게임은 보존하며 V3는 별도 브라우저 세션 키를 사용합니다.

원본 업비트 일봉 4종의 자산별 1,592행을 검증해 사용합니다. 시세 원본·정규화 CSV·세션 DB·인증정보는 Git에 넣지 않습니다. ZIP·README_V2.md·source_index.csv·archive는 보존합니다.

## Windows 로컬 실행·검증

`RUN_ERU_AI.cmd` 실행 후 [로컬 앱](http://127.0.0.1:8000)을 엽니다. 새 PC는 `SETUP_ERU_AI.cmd`, 종료는 `STOP_ERU_AI.cmd`를 사용합니다.

프론트엔드 의존성과 빌드는 로컬 캐시를 사용하는 `scripts/BUILD.ps1`로 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/BUILD.ps1
& "$env:LOCALAPPDATA\ERU-AI\alpha-v1-venv\Scripts\python.exe" -m pytest tests -q
Push-Location archive/ERU_AI_Investment_Simulator_V2
& "$env:LOCALAPPDATA\ERU-AI\alpha-v1-venv\Scripts\python.exe" -m unittest discover -s tests -v
Pop-Location
```

V3 브라우저 검증은 `scripts/guided_smoke.cjs`입니다. `ERU_BASE_URL`로 온라인 주소를 지정하고, `ERU_E2E_QUICK=1`이면 핵심 매매·가드·복원·모바일 확인까지만 실행합니다. 기본 실행은 실제 활성 300초, 이자 정산·자산명 공개·재도전까지 확인합니다. 원시 결과·세션과 화면은 Git에서 제외한 `test-results/`에 저장합니다.

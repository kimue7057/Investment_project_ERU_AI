# ERU AI Risk Guard 비트코인 시뮬레이터 화면 시안

기존 운영 앱과 독립된 클릭형 HTML 프로토타입입니다. 프레임워크나 외부 CDN 없이 실행합니다.

## 열기

- `RiskGuard_프로토타입.html`을 브라우저로 열면 로고·스타일·동작이 포함된 한 파일로 실행됩니다.
- 개발용 파일은 `index.html`, `styles.css`, `app.js`입니다.
- 로컬 미리보기는 이 폴더를 정적 서버로 제공하면 됩니다. 현재 작업 미리보기 주소는 `http://127.0.0.1:8847`입니다.
- 우측 상단 **전체 흐름 보기**에서 각 화면을 바로 열 수 있습니다.

## 살펴볼 흐름

소개 → 이메일 인증 시연 → 투자금 입력 → 세 사이클 자동 비교 → 결과 → 대응 복기 → 시연 기록.

- 이메일을 실제로 발송하지 않습니다. 시연 번호는 `000000`이며 **시연 계정으로 바로 계속하기**도 있습니다.
- 투자금 입력, 세 사이클 이동, 재생·정지·배속·다음 장면, 결과 바로 보기, 복기 번호 선택이 동작합니다.
- 새로고침 시 재생 위치·선택한 복기 장면을 복원하고, 브라우저 내 시연 기록에서 다시 엽니다.
- 로컬 저장 키는 `eru-riskguard-prototype-v1-*`만 사용합니다. 이메일은 저장하지 않습니다. 실제 서비스의 인증·계정·기록에는 접근하지 않습니다.

## 예시 데이터와 실제 계산의 구분

세 기간(2016.07~2020.04, 2020.05~2023.06, 2023.07~2026.05)은 제공된 엑셀의 사이클 구분입니다. 자산 곡선과 여섯 대응 장면은 화면 설명용 가상 예시입니다. 예시 금액은 입력 자본에 비례하며 최대 낙폭·회복 필요 상승률도 이 예시 곡선에서만 계산합니다. 실제 전략 성과나 가격으로 사용하면 안 됩니다.

BTC 전용 초기 현금 비중·실제 시세·원화 환산·수수료·이자·체결 시점·가드 운용 규칙은 실제 구현 단계에서 별도로 연결해야 합니다. 원본 엑셀의 혼합 포트폴리오 성과와 리플렛의 낙폭 수치를 BTC 단독 성과로 복사하지 않았습니다. 원본 시세·전략의 상세 수식·인증정보를 HTML에 넣지 않았습니다.

## 디자인 참고 자료

- 제공된 인쇄용 리플렛의 네이비·화이트·블루·골드 색상 구성, 제목과 여백 체계를 참고했습니다.
- 제공된 `RiskGuard_금빛리본_벡터.ai`는 PDF 호환 벡터 파일입니다. 원본을 수정하지 않고 투명 WebP로 변환해 `assets/riskguard-logo.webp`에 저장했습니다.
- 원본 리플렛과 AI 파일은 제공받은 위치에 보존하며 프로토타입에 원본 파일 자체를 복사하지 않았습니다.
- 리플렛의 실제 서비스 설명은 별도의 맥락이며, 이 시안의 자동 매매는 모의 비교의 화면 흐름입니다. 실제 거래소 주문 기능은 없습니다.

## 다시 묶기

`build_standalone.py`를 실행하면 수정된 소스와 로고를 한 파일 HTML에 반영합니다.

## 확인

브라우저에서 인증 시연·입력 검증·재생 제어·세 사이클 결과·복기 장면·새로고침 복원·로컬 기록·모달 키보드 조작을 확인했습니다. 320px·390px·768px의 가로 넘침과 외부 네트워크 요청이 없음을 확인했습니다. 운영 앱 코드·장부·시계·배포 구성은 변경하지 않습니다.

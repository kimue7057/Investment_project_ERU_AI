최초 루트에는 ZIP(38,229 bytes), README_V2.md(7,625 bytes), source_index.csv(4,047 bytes)만 존재했습니다. `ERU_AI_Investment_Flow_V1.mmd`는 루트 및 ZIP에서 발견되지 않았습니다. 프론트엔드·API·게임 장부·Git 이력은 없었습니다.

## 환경 및 저장소

로컬은 Git 저장소가 아니었습니다. GitHub 원격은 실제로 비어 있어 기존 원격 이력이 없음을 확인한 뒤 main 브랜치로 연결했습니다. 로그인한 GitHub 계정과 저장소 소유자가 일치했습니다. 기존 파일을 초기화하거나 다른 저장소로 덮어쓰지 않았습니다.

일반 Python 명령은 Windows 스토어 별칭이었고 npm은 PATH에 없었습니다. Codex의 Python/Node/pnpm 런타임을 확인해 사용했습니다. FastAPI 등은 별도 로컬 venv에 설치했습니다. Drive 파일시스템에서 pnpm의 심볼릭 링크 구성 오류가 재현되어, Node 의존성과 빌드는 %LOCALAPPDATA%의 프로젝트 전용 캐시로 분리했습니다.

# 영문 가명과 설명부터 시작하는 자산 상담

영문 이름은 유지한다. 초기 설정의 최신 흐름은 [직접 선택하는 초기 설정](직접선택_초기설정.md)으로 개정했으며, 아래 AI 자산 배분 상담은 이전 구현 기록이다.

코인을 이해한 뒤 배분을 논의하고 사용자가 제안을 선택하도록 투자 자산 상담을 개선했다. 포트폴리오 방향 → 투자 자산 → 리스크 조건의 세 상담 페이지는 유지한다.

[새 초기 설정으로 테스트](https://eru-ai-investment-simulator.vercel.app/?setup=1)

## 이름과 기록

네 코인의 표시 이름은 Asterra, Velora, Nexora, Lumera다. 실명을 나타내는 티커가 아닌 모의투자용 가명이며, 작은 아이콘에는 AS·VE·NE·LU를 표시한다. 내부 자산 키와 실제 시세·체결 장부는 바꾸지 않는다.

기존 세션의 한글 가명과 과거 A/B/C/D 표기는 공개 응답에서 새 이름으로 바꾼다. 대화, 알림 제목·설명, 승인 기록과 종목별 체결 내역의 표시가 일치하며 저장 원문은 보존한다.

## 사용 흐름

1. 앞 페이지에서 선택한 성향과 현금 비중을 확인한다.
2. 투자 자산 페이지에서 네 코인의 역할, 개요, 주요 위험을 먼저 읽는다. 기술·발행 구조는 펼쳐서 확인한다. 설명은 기존의 시점 검증된 공개 카탈로그를 사용한다.
3. **설명을 바탕으로 비중 제안받기**를 누르거나 궁금한 내용을 AI에 질문한다. 비교만 요청하면 비중 제안 없이 설명한다.
4. AI는 추천 종목의 특징과 위험을 먼저 설명하고, 선택한 현금 비중을 유지한 배분안과 이유를 제시한다.
5. 제안에는 전체 자산 기준 비중, 투자금 안에서의 비중, 배분 금액을 함께 표시한다. 현금 30%, 투자 70%에서 투자금의 60/40 배분은 전체 자산의 42/28%다. 코인 금액은 수수료 포함 예산이다.
6. **이 제안 선택 / 선택하지 않기**로 결정한다. 거절한 제안은 반영되지 않는다. 선택한 구성으로 조건 상담을 이어간다. 최종 투자 시작 승인 전에는 주문·시간 진행이 없다.

여러 코인을 담는 것이 손실 방지를 보장하거나 특정 코인이 더 안전하다는 설명은 추가하지 않는다. 공개 사실만 AI에 전달하고 기존 답변 검증과 근거 검토를 유지한다.

## 검증

- 서버 테스트 134개, archive unittest 10개 통과.
- scripts/BUILD.ps1의 타입 검사·프론트엔드 테스트 9개·운영 빌드 통과.
- 브라우저 UI 응답 픽스처로 설명 카드, 비중 제안 요청, 거절 후 재제안, 두 비중 기준, 사용자 선택, 조건 상담과 최종 승인 후 실제 다음 일봉 체결·가드까지 확인.
- 모바일 320px·390px에서 가로 넘침과 브라우저 오류 없음.
- 기존 한글 기록의 새 이름 표시와 원문 불변, 실제 식별자 공개 경계 회귀 검증.
- 운영 배포 후 실제 OpenRouter 응답 8회 모두 AI 연결 통과. 네 코인 설명만 요청했을 때 제안이 없고, 설명 카드의 버튼으로 현금 30%를 유지한 배분안을 받는 흐름을 확인했다. 제안 거절 → 투자금 내 60/40으로 재제안 → 선택 → 조건 상담 → 최종 승인 → 실제 초기 체결 2건 → 원가 손실 8% 가드까지 통과했다.
- 기존 운영 세션의 체결 3건과 새 영문 종목명 표시, 폴링 후 자산 화면 유지도 통과했다.
- 배포 후 최근 5분의 해당 배포 런타임 오류 로그 조회 성공, 오류 레코드 없음. 브라우저 검증에서도 페이지 오류 없음.

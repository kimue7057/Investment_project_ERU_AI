# OpenAI 직접 연결과 대화 개편

## 현재 구성

Vercel은 앱 배포와 기존 비공개 세션 저장을 담당합니다. AI 요청은 Python 서버에서 OpenAI Responses API로 직접 보냅니다. Gateway 키와 OIDC를 AI 호출에 사용하지 않습니다.

- `OPENAI_API_KEY`: Vercel 프로젝트의 Production Secret. 값은 출력·커밋하거나 브라우저에 전달하지 않습니다.
- `OPENAI_MODEL`: 선택 설정, 기본 `gpt-6-luna`.
- 주소: OpenAI의 `/v1/responses`. 기존 httpx를 사용하며 `store=false`로 호출합니다.
- 스키마에 따라 설명 문단, 근거 키, 선택적 비중 초안을 받습니다. 고정 문장 ID만 선택하던 이전 구현을 대체합니다.
- 한 질문에는 설명 생성과 독립적인 근거 검토의 두 API 호출이 발생합니다. 각각 읽기 제한 22초·10초, 연결 제한 5초이며 자동 재시도는 없습니다. 게임당 질문 40회·최소 2초 간격과 중복 UUID 처리를 유지합니다. 응답은 완성 후 표시하며 스트리밍은 사용하지 않습니다.

## 대화 맥락

설정 단계·선택 성향·현금 비중·선택 종목·투자금 내 비중을 구조화해 전달합니다. 서버는 전체 자산 비중을 다시 계산하며 종목/비중 설정이 미완료이면 명시적으로 null 처리합니다. 숨겨져 있던 기본 코인 A를 전체 설정의 논의 대상으로 강제하지 않습니다.

최근 12개 질문/답변/제안, 현재 초안, 초기 계획, 코인 A~D의 공개 설명·위험·보유 정보와 미해결 가드 근거를 함께 전달합니다. 시세 원본, 실제 식별자, 원문 URL, 미래 이벤트, 미확정 일봉은 전달하지 않습니다. 별도 외부 도구나 웹 검색은 제공하지 않습니다. 서버 세션에 대화를 저장하며 재접속 시 대화를 복구합니다. 긴 대화에서는 최근 12개 교환보다 오래된 발언이 모델 문맥에서 빠질 수 있습니다.

초기 안내는 단계별 고정 문구임을 구분하고 실제 대화창은 항상 보입니다. 답변에는 `OpenAI 직접 연결 · 모델명` 또는 인증·잔액/결제·요청 제한·연결·공개 사실 검증 실패에 따른 규칙 기반 상태를 표시합니다. 결제 오류는 API 사용 계정에서 처리해야 하며 Gateway 결제수단을 요구하지 않습니다.

## 승인과 공개 경계

구성 제안은 현금/A/B/C/D의 전체 자산 비중이며 합계 100을 Decimal 검증합니다. 설명 질문에는 불필요한 비중표를 붙이지 않습니다. 초안 반영 버튼은 설정만 갱신합니다. 거래는 별도 최종 확인 후 기존 서버 주문 경로에서 다음 일봉 시가에 체결됩니다.

출력 필드는 명시적으로 선택합니다. 응답 형식·근거 키·비중·실제 이름/티커/URL·연도·키 문자열과 유니코드로 숨긴 식별자를 검증하고, 별도의 모델 호출로 공개 사실 밖 사건·가격·금리·예측·미승인 거래 주장이 없는지 검토합니다. 실패한 생성 문장은 저장·공개하지 않고 검증된 고정 설명으로 대체합니다. 자유 문장의 의미 검토는 모델 판단을 포함하므로 규칙 검사와 악의적 질문 회귀 검증을 함께 유지합니다.

## 운영

환경변수 등록은 [Vercel 프로젝트 설정](https://vercel.com/eruty1/eru-ai-investment-simulator/settings/environment-variables)에서 진행하며 변경 후 새 배포가 필요합니다. Production Secret은 로컬 파일로 내려받지 않습니다. 로컬에서 실제 연결이 필요할 때만 별도 개발 키를 서버 환경에 등록합니다. 테스트는 가짜 자격증명·모의 HTTP 응답을 사용하며 유료 API를 자동 호출하지 않습니다.

공식 근거: [OpenAI Responses API](https://developers.openai.com/api/docs/quickstart), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [대화 상태](https://developers.openai.com/api/docs/guides/conversation-state), [모델](https://developers.openai.com/api/docs/models/gpt-6-luna).

## 검증 기록

- 백엔드 전체 pytest, 기존 archive unittest, 프론트엔드 타입 검사·테스트·빌드를 실행합니다.
- `scripts/mentor_smoke.cjs`: 성향·종목 맥락, 후속 비중 수정, 초안 반영, 승인 전 거래 없음, 재접속 대화 복구, 모바일과 공개 경계를 확인합니다. 실제 연결 확인에는 `ERU_REQUIRE_AI=1`을 사용합니다.
- 기존 초기 설정·승인 주문·가드·이자·복원 브라우저 검증도 수행합니다. 실행 결과는 Git에서 제외한 test-results에 저장합니다.

# 위험 발견과 직접 대응 선택

2026-10-21 사용자 요청을 반영했습니다. 운영 앱: https://eru-ai-investment-simulator.vercel.app

## 화면과 동작

- 신호 감지 시 시장을 멈추고 **위험 발견** 화면을 바로 엽니다.
- 신호의 제목·근거를 보여주고 보유 현황은 펼쳐 확인합니다. AI 대화, 질문 입력, 제안 수용 단계는 없습니다.
- **그대로 유지 / 종목 매수·매도 / 전체 비중 조정** 중 사용자가 직접 선택합니다.
- 매수 금액·매도 비율·전체 비중을 직접 입력하고 최종 확인합니다. 확인창을 닫거나 수정하면 주문하지 않습니다.
- 유지 승인 시 주문 없이 시장을 재개합니다. 매매 승인 시 시장을 재개하고 다음 일봉 시가에 주문을 체결합니다.
- 다른 화면에서도 위험 안내의 **대응 선택하기**로 돌아옵니다.
- 포트폴리오의 **비중 직접 조정**, 종목 상세의 **매수·매도 선택**도 동일한 직접 입력·승인 흐름입니다.

위험 감지 기준과 90일 알림 간격, 서버 시계·Decimal 장부·주문 승인 API·다음 일봉 체결 규칙은 기존대로 유지합니다. 예전 상담 기록은 계정에 보존합니다. 종료 후 AI 복기 요약은 이번 진행 화면 변경 범위에 포함하지 않았습니다.

## 검증

백엔드 pytest 177개, archive unittest 10개, 프론트엔드 타입 검사·테스트 19개·빌드를 실행했습니다. `scripts/direct_risk_smoke.cjs`는 로컬 QA 인증 공급자와 실제 검증 시세로 위험 자동 진입, AI 요청 0회, 유지 후 무주문, 수정한 25% 매도 체결, 비중 조정 체결, 승인 취소 시 무주문, 일반 화면 매매 진입과 320/390px를 확인합니다. 테스트 공급자·DB·시세는 운영 코드나 커밋에 포함하지 않습니다.

# 사용자 조건 제거와 기본 리스크 가드 복원 · 2026-10-21

## 적용 내용

사용자가 만드는 알림 조건과 초기 AI 조건 상담을 중단한다. 초기 설정은 성향 선택 → 코인·비율 선택 → 전체 계획 확인·동의 → 최종 승인으로 진행한다. 투자 중 AI 논의와 사용자 승인 매매는 유지한다.

이전 조건 상담 페이지에서 저장한 브라우저 초안은 성향·현금·선택 코인·비율을 유지해 코인 단계로 복원한다. 이전 사용자 조건이 저장된 진행 중 세션은 다음 서버 요청에서 기본 가드로 전환한다. 사용자 조건의 미처리 알림은 중단 처리하고, 장부·게임 시각·대기 주문·정지 상태와 기본 가드의 미처리 알림은 보존한다. 정지 중인 게임을 자동 재개하거나 주문을 취소하지 않는다. 전환은 판단 기록에 한 번 남긴다.

서버에서도 새 사용자 조건을 포함한 시작 요청과 이전 조건 상담 요청을 거절한다. 현재 AI에는 기본 가드 운영 맥락을 전달하고 risk_rules가 null인 구조화 응답만 허용한다. 과거 사용자 조건 코드는 기록 호환과 단위 검증을 위해 남기지만 현재 운영 요청에서는 적용하지 않는다.

## 확인한 기존 기본 가드

`backend/app/engine.py`의 `Engine.guard` 기준을 유지한다.

| 신호 | 기존 발동 기준 | 검토 방향 |
|---|---|---|
| 한 종목 집중 | 보유 코인의 평가액이 전체 자산의 60% 초과 | 분할 매도 |
| 주간 과열 | 보유 코인의 확정 주봉 RSI가 75 초과 | 분할 매도 |
| 주간 침체와 현금 여력 | 확정 주봉 RSI가 30 미만, 현금 비중 20% 이상 | 분할 매수 |
| 하루 급락 | 보유 코인의 확정 일봉 종가가 전일 종가보다 10% 초과 하락 | 비중 축소 |

RSI는 최근 15개 완료 주봉 종가로 만든 14개 가격 변화의 상승·하락 합계 비율이다. 완료되지 않은 주봉·일봉은 사용하지 않는다. 침체 매수 신호는 아직 보유하지 않은 코인에도 나타날 수 있다. 여러 기준이 겹치면 기존 코드의 우선순위를 유지한다.

AI 동행 모드에서는 공통으로 게임 속 90일의 알림 대기 기간을 적용한다. 같은 종목·같은 완료 주봉의 신호도 중복 처리하지 않는다. 5분 활성 재생 기준 90일은 약 19.74초다. 신호는 시장 정지와 검토 제안이며 자동 손절·자동 매수 주문이 아니다. 매매는 사용자가 승인하고 이후 다음 일봉 시가에 체결한다.

## 잦은 정지의 원인

사용자 조건 경로는 위 기본 가드를 대체했고 조건·종목별로 알림을 관리했다. 충족 상태가 이어져도 게임 속 7일 후 다시 알릴 수 있었으며, 기준 아래로 내려갔다 다시 도달하면 그 전에 다시 알릴 수도 있었다. 서로 다른 코인의 조건은 연속 발동할 수 있었다. 7일은 활성 재생 약 1.54초다.

`risk_policy.DEFAULT_RULES`에 남아 있는 집중 60%·원가 손실 15%·일봉 하락 10%·전체 손실 10% 목록은 예전 조건 상담의 출발점이며, 위 엔진 기본 가드와 다르다. 이번에는 이 목록을 기본 가드로 잘못 적용하지 않는다.

실제 검증 시세로 현금 30%·Asterra 42%·Velora 28%를 구성하고 모든 알림에 매매 없이 유지를 선택해 300초를 끝까지 계산한 비교에서는 사용자 원가 손실 8% 조건이 27회, 기존 기본 가드가 15회였다. 이는 해당 구성·유지 선택의 오프라인 엔진 검증이며 일반적인 알림 횟수를 보장하지 않는다. 시계 속도·초기 자금·실제 시세·수수료·장부는 변경하지 않았다.

## 검증

백엔드 회귀, archive의 기존 10개 테스트, scripts/BUILD.ps1의 타입 검사·프론트엔드 테스트·빌드를 실행한다. `scripts/builtin_guard_smoke.cjs`는 두 단계 설정에서 AI 요청 0건, 조건 단계 없음, 승인 전 무매매, 기본 가드, 유지 승인 후 즉시 재정지 없음, 이전 초안 복원과 모바일 너비를 실제 게임 API로 검증한다. 기존 연결 장애 검증 스크립트도 기본 가드를 사용하도록 갱신했다.

로컬 백엔드 152개, archive unittest 10개, 프론트엔드 13개·타입 검사·빌드가 통과했다. 기본 가드 화면 검증과 연결 오류 중단·수동 복구 검증도 통과했다. 운영 배포 후 실제 AI와 기존 세션의 전환을 추가 확인한다.

운영 `18e7820` / `dpl_4bUsMsoVmLMvPXsqKJPwTry9yM7F` 배포에서 새 흐름·기본 가드·유지 후 즉시 재정지 없음·모바일·이전 초안 복원 검증이 통과했다. 실제 8% 사용자 조건이 저장된 기존 게임은 기본 가드로 전환됐고, 전환 전후 거래·대기 주문 해시와 현금·게임 시각·정지 상태가 일치했다. 실제 OpenRouter 응답이 기본 가드를 설명하고 별도 8% 조건을 만들지 않는 것을 확인했다. 과거 사용자 조건을 썼던 이력은 현재 중단과 구분해 AI 맥락에 전달한다. 운영 health 200과 최근 오류 로그 0건을 확인했다. 원시 결과는 Git에서 제외한 test-results에 보관한다.

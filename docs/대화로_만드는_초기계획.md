# ERU AI와 대화로 만드는 초기 계획

> 단일 상담 화면과 자동 초안 정리는 이전 구현 기록입니다. 최신 흐름은 [세 상담 페이지와 사용자 선택](세_상담페이지와_사용자선택.md)을 확인하세요.


[새 상담에서 테스트](https://eru-ai-investment-simulator.vercel.app/?setup=1)

초기 설정 화면을 하나의 이어지는 상담으로 바꿨습니다. 사용자가 성향 버튼·비중 입력칸·코인별 조건 편집기를 순서대로 채우지 않습니다. ERU AI와 투자 경험, 기대와 걱정, 감수 가능한 손실을 이야기하면서 자금 배분·투자 종목·리스크 조건을 함께 정합니다.

## 화면과 진행

주 화면은 **우리의 투자 상담**입니다. 옆에는 읽기 전용 **함께 정리한 계획**이 있습니다. 대화의 구조화된 제안이 이 계획에 자동으로 모입니다. 별도의 ‘초안에 담기’ 버튼도 없습니다. 정리된 내용은 승인 전 제안이며 매매나 조건 확정을 의미하지 않습니다.

예를 들어 “처음이라 손실이 걱정돼”라고 시작하면 AI가 필요한 질문을 합니다. “현금을 어느 정도 남기면 좋을까?”, “그 구성에서 언제 다시 판단하면 좋을까?”처럼 같은 대화에서 이어갑니다. 조건은 전체 자산이나 보유 종목에 공통 적용하는 기준부터 논의하며, 사용자가 코인마다 수치를 직접 입력할 필요가 없습니다. 특정 종목 조건도 대화에서 요청할 수 있습니다.

“그 손실 기준만 8%로 바꾸자”라고 하면 다른 자산 배분은 유지하고 조건을 수정합니다. 성향·현금 비중만 바꾸는 제안은 기존 종목의 상대 비율을 유지해 전체 자산 기준으로 환산합니다. 종목 추천을 요청하면 미선택 상태에서도 AI가 확인된 특성과 위험을 비교해 구성안을 제안할 수 있습니다.

성향·배분·리스크 조건이 정리되면 **함께 만든 계획 확인**이 나타납니다. 계획과 현금 이자·리스크 조건을 검토하고 동의한 뒤 **이 계획으로 투자 시작 → 확정하고 자동 투자 시작**으로 승인합니다. 승인 전에는 서버 초기 계획·리스크 조건·주문·게임 시각이 바뀌지 않습니다. 승인한 주문은 기존처럼 다음 일봉 시가에 체결합니다.

## 유지하는 경계

- 새 상담은 자산 구성이나 리스크 조건을 미리 채우지 않습니다. 조건 미논의와 명시적으로 알림을 끈 빈 목록을 구분합니다.
- AI 제안만 상담 초안에 정리합니다. 규칙 기반 대체 안내를 개인화된 새 계획처럼 적용하지 않습니다. 연결 실패 시 기존 초안을 보존합니다.
- 새로고침 시 대화와 상담 초안을 복원하고, 같은 응답을 다시 반영하지 않습니다. 최종 동의는 다시 확인합니다.
- 구조화된 제안과 공개 사실을 서버에서 검증하고 별도로 근거를 검토합니다. 실제 식별자·원문 URL·미래 사건·미확정 일봉은 노출하지 않습니다.
- 기존 진행 중 게임의 가드·매매·Decimal 장부·서버 시계·거래 내역·이자는 유지합니다. 조건 지표와 감지 기준은 [리스크 조건 구현 기록](AI_초기상담과_리스크조건.md)을 따릅니다.

## 검증

`scripts/conversation_smoke.cjs`가 현행 초기 상담 검증입니다. 숫자 입력·선택 폼과 단계 이동 없이 첫 상담, 구성·공통 조건 통합 제안, 후속 조건 수정, 자동 계획 정리, 복원, 승인 전 무주문, 실제 다음 시가 체결과 조건 감지, 320px·390px 화면을 확인합니다.

기본 실행은 브라우저 응답 픽스처를 사용해 UI 연결을 검증하며 실제 AI라고 보고하지 않습니다. `ERU_REQUIRE_AI=1`과 운영 `ERU_BASE_URL`을 지정한 실행은 실제 OpenRouter 응답을 요구합니다. 원시 대화·세션·화면은 무시 경로 `test-results/`에만 저장합니다.

이전 단계형 화면을 조작하는 `setup_smoke.cjs`, `mentor_smoke.cjs`, `risk_consult_smoke.cjs`, `guided_smoke.cjs`, `history_smoke.cjs`의 초기 진입 부분은 이전 UI의 검증 기록입니다. 현행 초기 상담 검증에는 위의 새 스크립트를 사용하고, 진행 중 기존 세션의 복원은 `history_restore_smoke.cjs`로 확인합니다.

- 로컬 응답 픽스처 검증과 운영 환경 실제 OpenRouter 3회 대화 모두 통과. 실제 AI와 초기 상담 → 현금 30%·새벽코인 42%·물결코인 28% 및 공통 조건 작성 → 전체 손실 10%를 8%로 후속 수정 → 자동 초안 정리·복원 → 최종 승인 → 초기 체결 2건 → 종목 공통 비중 35% 조건 감지를 확인했습니다.

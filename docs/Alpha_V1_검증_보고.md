# Alpha V1 구현·검증 보고 · 2026-10-19

## 완료 범위

현금과 코인 A~D를 대상으로 상품 탐색·기술/공급/위험 정보·날짜별 공개 자료·초기 1억 원 배분·300초 재생·일시정지/재개·금액/비율 주문·주문 취소·목표 비중 저장·리밸런싱·규칙 기반 AI 매수/매도 검토·선택 기록·성과 평가·실제 정체 공개·재도전을 구현했습니다.

Figma 18개 화면을 검토하고 공통 디자인 토큰 및 레이아웃으로 연결했습니다. React/TypeScript/Vite/Lightweight Charts, Python/FastAPI/SQLite를 사용합니다. 원본 자료와 신규 개발 파일은 분리했습니다.

## 실제 브라우저 플레이 기록

시작 화면 → 상품 설명 → 합계 오류 차단 → 초기 배분 → 수동 매수 주문 → 시장 재개/체결 → 정지 시간 불변 확인 → 리밸런싱 주문 → 모바일 검사 → 전체 시장 재생 → 성과 → 정체 공개 → 재도전 초기화 순서로 실행했습니다.

- 전체 시장의 활성 재생 시간: **300초**.
- 후반 자동 테스트 루프의 실제 벽시계 시간: **318.118초**. 자동 일시정지/응답 처리 시간이 추가됩니다.
- 상태 및 공개 응답 검사: 762회.
- 자동 정지 처리: 40회. 제안 수용 2회.
- 체결 거래: 11건.
- 테스트 전략의 최종 자산: 156,064,672.92원. 수익률 +56.0646729%, MDD 60.4938933%.
- 브라우저 JavaScript 오류: 0건.
- 재도전: 새 세션, 1억 원 현금, 재생 0초, 거래 내역 없음 확인.

위 수치는 특정 테스트 조작의 관측 결과이며 고정된 예시 수익이나 추천 전략이 아닙니다. 단순 초기 배분 유지 전략의 결과와 별도로 실제 장부에서 계산했습니다. 전체 재생 검증 후 추가된 매수 제안 경로는 전용 테스트와 최종 API/전체 기간 회귀 테스트로 확인했고, 최종 프론트엔드 빌드도 별도로 브라우저 조작 검증했습니다.

스크린샷과 원시 보고는 `test-results/01-intro.png`~`09-reveal.png`, `browser-report.json`에 있습니다. 스크린샷은 기존 Figma와 비교해 데스크톱·390px 모바일의 넘침, 모달, 가격 차트, 버튼 동작을 확인했습니다. 리사이즈 시 차트의 높이가 증가하던 문제와 상태 조회/주문 경합으로 클릭이 사라지던 문제를 수정하고 재검증했습니다.

## 실행 및 변경 파일

- 실행: 루트 `RUN_ERU_AI.cmd` 또는 http://127.0.0.1:8000.
- 종료: `STOP_ERU_AI.cmd`.
- 새 환경 설치: `SETUP_ERU_AI.cmd`.
- 수정 후 빌드: `scripts/BUILD.ps1`.
- 주요 구현: `backend/app/{market,engine,main}.py`, `frontend/src/{App,Chart,model,style}.*`.
- 데이터: `scripts/{collect_upbit,validate_data,probe_history}.py`, `data/metadata/validation.json`.
- 상세 사용·체결 규칙: 루트 README.md.

## 남은 범위와 제한

- 주식 E/F, 부동산 G는 상품 미확정으로 거래를 차단합니다.
- 자료 이벤트는 검증된 A~D 8건이며 전체 과거 뉴스나 기술문서의 포괄적 아카이브가 아닙니다. 기존 E/F/G 후보 자료는 공개하지 않습니다.
- 생성형 AI 자연어 서비스는 연결하지 않았으며 재현 가능한 규칙과 설명을 제공합니다.
- 실제 일봉 기반으로만 체결·평가하며 장중 주문장·슬리피지·체결 지연·세금은 모델링하지 않습니다.
- 게임의 끝인 2026.08.05에 아직 확정되지 않은 당일 일봉 종가는 사용하지 않습니다.
- 데이터 및 문서의 공개 재배포/상업 라이선스는 미확보입니다. 현재는 로컬 내부 검토용입니다.
- pytest 실행에 사용한 Starlette의 httpx TestClient에 향후 전환을 알리는 경고 1건이 있습니다. 테스트 실패 및 실제 서버 오류는 없습니다.
- Google Drive 경로의 Git/SQLite를 여러 PC에서 동시에 쓰지 않습니다. Node 의존성과 빌드 캐시는 PC 로컬에 둡니다.

## Git 운영

비어 있던 지정 원격 저장소에 main 브랜치를 연결했습니다. 원본 보존, 서버/데이터, 경쟁 상태 수정, 웹 UI/실행/문서 단위로 커밋합니다. 강제 푸시나 기존 이력 삭제는 사용하지 않습니다. 시세 CSV·원본 페이지·세션 DB·의존성·빌드 산출물·인증정보는 Git에서 제외합니다.

# AI 동행 투자 V3 구현 · 2026-10-20

[온라인 테스트](https://eru-ai-investment-simulator.vercel.app) · [상태 확인](https://eru-ai-investment-simulator.vercel.app/api/health)

## 사용자 흐름

자산 이해, AI와 질문·구성 초안, 초기 주문 확인·승인, 다음 일봉 시가 자동 체결, 포트폴리오·이자 관찰, 가드 정지와 논의, 유지·개별 주문·전체 비중 조정 승인, 체결 결과, 종료 복기까지 연결했습니다.

시작 전 비중 저장·AI 질문은 거래를 만들지 않습니다. 구성 확정 버튼과 최종 승인 단계를 거쳐 초기 주문을 한 번 접수합니다. 리스크 가드는 기본 분석 기능이며 자료 공개 알림 없이 실제 위험 신호만 정지시킵니다. 중요 신호 사이에 90 게임일의 간격을 두고 동일 신호를 중복 처리하지 않습니다. 가드를 닫거나 일반 재개 버튼을 누르는 것으로 대응을 대신하지 않으며 유지·매매를 명시적으로 선택합니다.

전체 비중 조정은 다음 시가에서 매도 후 실제 가용 자금으로 매수합니다. 수수료가 자금 한도를 넘지 않도록 기존 Decimal 계산을 유지했고, 현금 100% 전환에서 전량 매도의 미세 잔량이 남지 않도록 수정했습니다. 초기 계획은 변경 후에도 복기 기준으로 보존합니다.

주문 묶음은 초기·비중 조정·개별 매매를 구분합니다. 접수·예약과 실제 체결을 별도로 표시하며, 기존 미체결 주문이 있으면 다음 승인으로 덮어쓰지 않습니다. 종료 전 다음 체결 일봉이 없으면 새 주문을 거절합니다.

## 대기 자금 이자

과거 실제 기준금리를 참조하는 **교육용 이자 모델**입니다. 실제 예금·적금 상품 수익률이나 채권 수익률을 재현한 것으로 표시하지 않습니다.

- 근거: [한국은행 기준금리 추이](https://www.bok.or.kr/portal/singl/baseRate/list.do?menuNo=200656), 2026-10-20 확인.
- 시작에 적용하는 연이율은 2022-10-12 변경분 3.00%입니다. 이후 게임 기간에 해당하는 변경은 2022-11-24 3.25%, 2023-01-13 3.50%, 2024-10-11 3.25%, 2024-11-28 3.00%, 2025-02-25 2.75%, 2025-05-29 2.50%, 2026-07-16 2.75%입니다.
- 날짜만 있는 원본의 당일 공표 시각을 추측하지 않고 변경일 **다음 날 00:00 KST**부터 적용합니다. 미래 변경 목록은 브라우저나 모델 입력에 전달하지 않습니다.
- 계산: 운용 가능한 원금 × 해당 구간 연이율 × 경과 초 / 31,536,000. 365일 기준 세전 단리이며 게임에서 실제로 경과한 구간만 반영합니다.
- 시작 전·일시정지·AI 논의 중에는 추가 이자가 없습니다. 서버가 정한 게임 시각을 기준으로 금리 변경점과 매매 체결점마다 구간을 나눕니다.
- 주문 예약금은 이자 대상에서 제외합니다. 초기 예약금은 코인 매수 예산 합계, 개별 매수는 승인 예산, 비중 조정은 전체 대기 자금 원금입니다.
- 매도 대금은 실제 체결 후 운용합니다. 미수이자는 별도 장부에 기록하고 총자산에 포함하되 주문에는 사용하지 않습니다.
- 종료 시 미수이자를 원금 잔고에 한 번 합치고 정산 완료로 표시합니다. 총자산에 이자를 중복 가산하지 않습니다. 이자에 다시 이자를 붙이지 않습니다.
- 반복 조회·클라우드 체크포인트 재구성·장기 정지 복원에서 중복 또는 누락되지 않도록 검증합니다.

E/F/G는 확정하지 않았습니다. 유동성 대기 자금, 정기예금·적금, 채권의 차이는 설명하며 미확정 실상품을 거래 목록에 넣지 않습니다. 코인 스테이킹 수익은 임의로 추가하지 않습니다.

## AI 연동과 공개 경계

Python의 기존 httpx로 [Vercel AI Gateway Chat Completions REST](https://vercel.com/docs/ai-gateway/openai-compat/rest-api)를 사용합니다. 배포의 OIDC 인증을 사용하며 개발 환경은 서버 전용 AI_GATEWAY_API_KEY 또는 VERCEL_OIDC_TOKEN을 지원합니다. 자격증명은 브라우저에 노출하지 않습니다.

실시간 모델 목록에서 확인한 openai/gpt-6-luna를 구성했습니다. 사용자의 질문, 현재 구성 초안, 최근 대화, 현재 시점에 허용한 사실만 전달합니다. 모델은 JSON 스키마에 따라 설명 항목 ID와 합계 100의 구성 초안을 반환합니다. 서버는 허용된 항목과 비중을 다시 검증하고, 공개 문장은 검증된 사실에서 조립합니다. 모델의 임의 문장·링크·실제 식별자는 공개하지 않습니다.

질문은 최대 600자, 게임당 40회, 연속 요청은 최소 2초 간격입니다. 요청 UUID를 저장해 같은 질문 요청을 재전송해도 모델을 다시 호출하지 않습니다. 논의 시작에서 시장을 정지·저장하고 외부 호출을 장부 갱신과 분리합니다. 결과를 저장하기 전에 같은 게임 시점과 요청인지 확인합니다. AI가 직접 주문하거나 시간을 바꾸는 도구는 없습니다.

**실연결 제한:** OIDC 인증으로 실제 요청을 보냈지만 Vercel이 HTTP 403 customer_verification_required를 반환했습니다. 팀에 유효한 결제수단을 등록해야 AI Gateway를 사용할 수 있다는 응답입니다. 결제수단 등록이나 유료 플랜 전환을 대신 수행하지 않았습니다.

현재 이 조건에서는 규칙 기반 설명과 성향별 구성 초안을 제공하고 답변마다 ‘규칙 기반 안내’를 표시합니다. 미래 정보·실제 자산명 질문은 공개 범위 안내로 제한합니다. 모델 연결 성공 시에는 ‘AI와 논의 · 공개 사실 검증 완료’를 표시합니다. 사용자에게 연결 여부를 숨기지 않습니다.

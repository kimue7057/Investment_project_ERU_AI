# 초기 포트폴리오 설정 개편 · 2026-10-20

초기 설정을 **성향 → 현금·투자 배분 → 종목 선택 → 최종 확인**으로 바꿨습니다. 이후 승인 매매·가드·이자 계산·서버 시계·장부는 유지합니다.

## AI와 진행하는 설정

ERU 투자 도우미가 단계별 질문을 하고 사용자의 선택에 따라 이유와 금액을 설명합니다. 현재는 규칙 기반 안내임을 표시합니다. 추가 질문과 구성 제안 적용도 가능하며, 제안 적용이나 단계 이동만으로 주문하지 않습니다.

| 안내용 성향 | 현금 | 투자 |
|---|---:|---:|
| 안정형 | 60% | 40% |
| 균형형 | 30% | 70% |
| 공격형 | 10% | 90% |

비중은 수정 가능한 출발점입니다. 성향 판정·원금 보장이 아니며, 기준 비중을 바꾸면 ‘직접 조정’을 표시합니다.

사용자가 **현금·투자 2분류로 구성하고 안전 성향을 현금 비중에 반영**하는 방식을 선택했습니다. 별도 안전자산·채권 상품이나 미확정 E/F/G를 추가하지 않습니다. ‘이자형 대기 자금’ 표시는 **현금 (이자 수익)**으로 바꿨으며 기존 이자 장부와 정책은 유지합니다.

## 두 단계 비중

총자금에서 현금과 투자 금액을 먼저 나누고, 그 투자금 안에서 코인 A~D를 직접 고릅니다. 아무 종목도 미리 선택하지 않습니다. 선택한 종목에 균등 배분한 뒤 직접 수정할 수 있고, 종목별 특징과 위험 설명을 제공합니다.

예를 들어 현금 30%·투자 70%에서 투자금 내 A 60%·B 40%면, 전체 자산은 현금 30%·A 42%·B 28%입니다. 초기 1억 원에서 A 4,200만 원·B 2,800만 원이 수수료 포함 주문 예산이며 C·D에는 주문하지 않습니다.

내부 비중과 전체 비중을 함께 보여줍니다. 전체 자산 0.01% 단위로 반올림을 배분해 합계 100%를 유지합니다. 선택 해제 시 해당 종목의 비중을 제거하고, 미선택·잘못된 내부 합계는 확인 단계로 진행하지 못하게 합니다.

현금 100%는 종목 선택과 초기 주문 없이 시작할 수 있습니다. 준비 중에는 거래와 게임 시간이 흐르지 않습니다. 성향·단계·종목·비중은 같은 게임에서 새로고침해도 복원하며 이자 조건 동의는 다시 확인합니다.

## 검증

- scripts/BUILD.ps1로 타입 검사·프론트엔드 테스트 5개·프로덕션 빌드 통과.
- 백엔드 전체 회귀 55개와 기존 archive unittest 10개 통과. 새 성향 표현과 현금 비중, 준비 중 무주문을 포함합니다.
- scripts/setup_smoke.cjs: 세 성향, 현금·투자 연동, 미선택·합계 오류 차단, 전체 비중 42%/28% 환산, 복원·재동의, 실제 초기 체결, 현금 100% 시작, 320px·390px 가로 넘침 없음.
- 갱신한 scripts/guided_smoke.cjs: 새 설정 이후 초기 매수·가드 정지·25% 매도·현금 100% 비중 조정·복원·모바일 통과.

시계·이자·장부 실행 코드를 변경하지 않아 이번 검증은 초기 설정과 기존 매매 연결에 집중합니다. 이전 전체 300초 온라인 재생 기록은 [V3 구현 기록](AI_동행투자_V3_구현.md)에 보존합니다. 시세 원본·CSV·세션·인증정보·원시 화면은 커밋하지 않습니다.

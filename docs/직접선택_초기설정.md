# 직접 선택하는 초기 설정

[새 설정부터 테스트](https://eru-ai-investment-simulator.vercel.app/?setup=1)

## 사용자 흐름

1. 포트폴리오 유형의 특징을 읽고 **균형형 / 안정형 / 공격형 / 기타** 중 직접 선택한다. 기본 배분은 각각 현금 30%·투자 70%, 현금 60%·투자 40%, 현금 10%·투자 90%다. 기타는 현금 비중을 직접 입력하며 투자 비중을 나머지로 계산한다. 현금 100%도 가능하다.
2. 코인의 역할·특징·위험을 읽고 체크박스로 투자 대상을 선택한다. 선택하면 옆의 비율 박스가 활성화된다. 투자금 안에서 각 코인의 비율을 입력하거나 균등 배분한다. 선택한 코인마다 양수 비중, 합계 100%, 소수 둘째 자리까지 유효해야 다음 단계로 간다. 체크를 해제하면 해당 종목의 비중을 0으로 지운다. 비율이 맞지 않으면 전체 자산 배분과 시작을 막는다.
3. 마지막에 **매매 조건의 목적**을 보고 AI 제안을 요청한다. 손실 관리(원가 대비 종목 손실/시작 자금 대비 전체 손실), 급락 확인(확정 일봉 하락률), 쏠림 관리(전체 자산 내 종목 비중)의 의미를 설명한다. 대화로 조정할 수 있고, 사용자가 제안을 선택하거나 거절한다.
4. 전체 계획을 확인하고 동의한 뒤 초기 주문을 최종 승인한다. 초기 매수는 다음 일봉 시가에 체결한다. 설정·대화·조건 선택만으로 시간이나 주문을 진행하지 않는다.

첫 두 단계에는 AI 입력창·비중 제안 버튼·모델 호출이 없다. 조건 상담에만 AI UI를 렌더링한다. 기타는 서버에 custom으로 전달해 임의로 다른 성향으로 해석하지 않는다. AI는 직접 정한 자산 구성을 바꾸지 않고 조건만 제안한다.

조건은 자동 손절·자동 추가 매수 주문이 아니다. 기준에 도달하면 시장 정지 → AI와 대응 논의 → 사용자가 유지·매수·매도를 승인한다. 가격 지정·정기 분할 자동 주문 기능을 추가하지 않는다.

## 선택 보존과 변경

새 직접 설정은 세션별 버전 저장소를 사용한다. 이전 상담형 초안은 보존하고 새 설정 화면에서는 직접 선택부터 진행한다. 기존 투자 진행 중 세션·체결 장부는 변경하지 않는다.

현금·성향·코인 선택·비율 변경 시 이미 선택한 조건을 해제한다. 이전 구성에 맞춘 조건은 현재 구성과 맞지 않으면 선택할 수 없다. 원래 비중으로 돌아와도 해제된 조건은 새로 제안받아 선택해야 한다. 제안 거절은 현재 계획에 반영하지 않는다. 새로고침 시 직접 선택과 현재 페이지, 유효한 조건 선택을 복원한다.

모바일에서는 선택한 코인의 비율 박스로 이동하는 버튼을 제공한다. 전체 자산 기준 비중과 금액은 투자금 내 비율을 환산해 표시한다. 금액은 수수료 포함 예산이다.

## 검증

- 서버 pytest 136개, archive unittest 10개 통과.
- scripts/BUILD.ps1의 타입 검사·프론트엔드 테스트 13개·운영 빌드 통과.
- scripts/manual_setup_smoke.cjs로 첫 두 단계 AI 호출 0건, 네 유형 선택, 기타 비중 검증, 체크·해제, 합계 오류 차단, 균등 배분, 조건 제안 거절·선택, 배분 변경 후 조건 해제, 새로고침 복원을 확인했다.
- 브라우저 UI 픽스처로 최종 승인 전 거래 없음 → 실제 초기 체결 2건 → 원가 손실 8% 가드까지 통과했다. 모바일 320px·390px 가로 넘침과 브라우저 오류 없음.

규칙·공개 시점·시세 원본·Decimal 장부·서버 시계는 기존 구현을 유지한다. 원시 검증 결과와 세션은 Git에서 제외한 test-results/에만 저장한다.

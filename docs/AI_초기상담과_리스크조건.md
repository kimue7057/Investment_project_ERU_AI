# 초기 AI 상담과 리스크 조건 · 2026-10-20

[새 초기 설정에서 테스트](https://eru-ai-investment-simulator.vercel.app/?setup=1)

성향 → 현금·투자 배분 → 종목 선택 → **리스크 조건 상담** → 최종 확인 순서입니다. 각 단계에서 ‘AI와 이 단계 상담하기’나 자유 입력으로 이어서 상담합니다. 고정 안내와 실제 AI 답변의 연결 상태를 구분합니다.

종목을 고르기 전에도 AI가 성향·현금 비중을 제안할 수 있습니다. ‘이 성향·자금 배분을 초안에 담기’로 설정에 반영한 뒤 투자할 종목을 함께 고릅니다. 코인 구성 제안과 리스크 조건 제안도 각각 초안에 담으며, 최종 승인 전에는 주문하거나 조건을 확정하지 않습니다.

## 조건을 만드는 방법

예: “기존 조건을 유지하고, 새벽코인은 매수원가보다 8% 이상 손실이면 알려줘.” 이어서 “방금 추가한 조건만 9%로 바꿔줘”라고 수정할 수 있습니다. AI에는 현재 설정과 최근 대화 12개, 현재 공개 사실만 전달합니다. 제안은 설명 검증과 별도 근거 검토를 통과해야 표시합니다.

‘이 알림 조건을 초안에 담기’를 누르면 오른쪽 조건 편집기에 전체 제안이 반영됩니다. 지표·대상·수치를 직접 수정하거나 켜기·끄기·추가·삭제할 수 있습니다. 최대 8개이며 같은 지표·대상은 하나만 설정합니다. 수치는 0 초과 100% 이하, 소수 둘째 자리까지입니다.

| 지표 | 판단 기준 | 대상 |
|---|---|---|
| 한 종목 쏠림 | 종목 평가액 ÷ 미수이자 포함 총자산 | 모든 보유 종목에 각각 또는 특정 코인 |
| 매수원가 대비 손실 | 수수료 포함 이동평균 잔여 원가 대비 평가손실 | 모든 보유 종목에 각각 또는 특정 코인 |
| 하루 가격 하락 | 가장 최근 확정 일봉의 전일 종가 대비 하락률 | 모든 보유 종목에 각각 또는 특정 코인 |
| 전체 자산 손실 | 시작 자금 1억 원 대비 미수이자 포함 총자산 손실 | 전체 자산 |

임계값 이상이면 충족입니다. 예상 매도 수수료는 평가액에서 차감하지 않습니다. 미보유 종목의 조건은 매수해 보유하기 전에는 작동하지 않습니다. 가격 지정·뉴스·시간·임의 코드·복합 수식은 실행 조건으로 지원하지 않으며 AI가 대신 실행하지 않습니다.

처음 제공하는 수정 가능한 초안은 쏠림 60%, 종목 손실 15%, 하루 하락 10%, 전체 손실 10%입니다. 투자 성과를 보장하는 권장 기준이 아닙니다. 조건을 모두 끄거나 삭제하면 조건에 따른 자동 정지가 없다는 안내를 최종 확인에 표시합니다.

## 투자 중 동작

최종 화면과 승인창에서 포트폴리오·조건을 함께 확인합니다. 서버가 승인 시 조건을 검증하고 세션에 저장합니다. 초기 매수는 기존처럼 판단 이후 다음 일봉 시가에 체결합니다. 조건은 서버 장부와 해당 게임 시점의 확정 시세로 평가합니다.

켜진 조건 중 하나라도 충족하면 **알림 → 시장 정지 → AI와 대응 논의 → 유지 또는 매매 승인**으로 이어집니다. 자동 손절 주문이 아닙니다. 알림에는 지표·설정 기준·관측값을 표시합니다. 조건별·종목별로 재알림을 관리해 다른 조건이 가려지지 않게 합니다. 충족이 이어지면 게임 7일 뒤 재알림하고, 기준을 벗어났다가 다시 도달하면 새로 알립니다. 여러 조건이 충족하면 대응 후 다른 조건의 알림이 이어질 수 있습니다.

시작한 뒤 ‘내가 정한 리스크 조건’에서 확정한 설정을 확인합니다. 이번 범위의 조건 수정은 초기 설정에서만 지원합니다. 새로고침해도 조건·장부·거래 기록을 복원합니다. 기존 조건 필드가 없는 세션은 기존 기본 가드를 유지하며, 새 조건으로 임의 변경하지 않습니다.

OpenRouter 연결 실패 시 사유와 규칙 기반 안내를 표시하고, 자연어 조건을 해석해 적용했다고 주장하지 않습니다. 이때도 조건 편집기로 직접 설정할 수 있습니다. 실제 식별자·미래 사건·미확정 시세·비밀키를 브라우저나 AI 맥락에 추가하지 않습니다.

## 검증

조건 형식·범위·중복·실행 코드 거절, 실제 다음 시가 체결 이후 감지, 임계값 변경·비활성화·미보유 대상, 독립 조건·재알림·재진입, 미수이자 포함 전체 손실, 기존 세션 호환, AI 제안의 미확정 상태와 승인 저장을 회귀 테스트합니다.

`scripts/risk_consult_smoke.cjs`는 초기 상담과 후속 조건 수정, 초안 적용, 수치 오류 차단, 복원, 최종 승인, 실제 시세에 의한 정지, 320px·390px 화면을 검증합니다. `ERU_REQUIRE_AI=1`은 배포된 실제 OpenRouter 응답을 요구합니다. 원시 대화·세션·화면은 무시 경로인 `test-results/`에만 저장합니다.

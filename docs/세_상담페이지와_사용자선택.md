# 세 AI 상담 페이지와 사용자 선택

[새 상담에서 테스트](https://eru-ai-investment-simulator.vercel.app/?setup=1)

초기 설정은 세 페이지입니다. 각 페이지의 AI는 같은 ERU AI 모델을 사용하되 상담 목적과 제안 종류를 구분합니다.

1. **포트폴리오 방향 상담**: 투자 경험·기대·걱정을 이야기하고 성향과 현금·투자 비중 제안을 비교합니다.
2. **투자 자산 상담**: 영문 가명 네 코인의 설명 카드를 먼저 읽고 **설명을 바탕으로 비중 제안받기**로 배분을 논의합니다. 전체 자산/투자금 안에서의 비중과 배분 금액을 확인하고 제안을 선택합니다. [영문 가명과 자산 설명 상담](영문가명과_자산설명_상담.md)
3. **조건 상담**: 선택한 구성을 바탕으로 재논의할 손실·급락·쏠림 등의 조건을 논의합니다.

AI 제안 카드에서 **이 제안 선택 / 선택하지 않기**로 사용자가 직접 결정합니다. 제안을 받았거나 대화로 ‘좋아’라고 말한 것만으로 선택되지 않습니다. 선택하지 않은 제안은 계획을 바꾸지 않습니다. 선택한 내용만 옆의 ‘내가 선택한 계획’과 다음 상담에 전달합니다.

현재 페이지의 제안을 선택해야 다음 상담으로 이동할 수 있습니다. 새 제안이 추가되면 해당 제안도 선택 여부를 결정합니다. 기존 선택을 유지하면서 새 제안을 거절할 수도 있습니다. 세 페이지 선택 뒤 **전체 계획 확인 → 이 계획으로 투자 시작 → 확정하고 자동 투자 시작**으로 전체 계획과 실제 초기 주문을 승인합니다.

이전 상담으로 돌아갈 수 있습니다. 성향·현금 비중을 바꾸면 자산·조건 선택을 해제하고, 자산 구성을 바꾸면 조건 선택을 해제합니다. 이전 기준으로 생성된 오래된 제안은 다시 선택하지 못하게 막습니다. 같은 의미의 제안을 다시 선택한 경우 불필요하게 이후 선택을 초기화하지 않습니다. 선택과 거절, 페이지 위치는 같은 브라우저의 게임별 저장소에 복원하며 기존 진행 중 게임은 유지합니다.

## AI 지침과 검증 수정

연결은 OpenRouter, 기본 모델은 `openai/gpt-6-luna`입니다. 공개 사실·사용자 선택·최근 사용자 발언을 주고 답변을 생성한 뒤 별도 근거 검토를 합니다.

사용자가 보고한 네 문장을 기존 운영 버전에서 재현했을 때 두 번째 답변이 일반 검증 실패로 대체됐습니다. 과거 구현은 형식·공개 범위·근거 검토 실패를 같은 문구로 표시해 그 응답의 세부 실패 단계까지 단정할 수 없었습니다. 다음 문제는 코드에서 확인하고 수정했습니다.

- 매수 판단 상담과 자동 조건 주문 실행을 구분합니다. 금액·현금 유보·자산 특성과 분할 판단은 상담할 수 있으며, 미지원 자동 주문을 가능하다고 말하지 않습니다.
- ‘10% 이상’, 다음 발언 ‘매수원가 대비’를 연결하도록 생성·검증 지침에 최근 사용자 선호를 명시합니다. 같은 기준을 반복해서 묻지 않습니다.
- 실패 안내를 정상 AI 상담으로 다음 요청에 전달하지 않습니다. 사용자의 질문은 보존하고 무관한 기본 종목 설명으로 바꾸지 않습니다.
- 형식·공개 범위·근거 검토 실패를 구분합니다. 근거 검토는 새 시장 정보·식별자·미래 주장·이미 실행했다는 주장·미지원 자동 주문 등 명시적 위반 사유를 구분하고, 허용된 교육 비교와 사용자 선호를 위반으로 취급하지 않습니다. 고정된 단계·사유 코드만 서버에 기록합니다. 원문 답변·질문·키를 진단 로그에 기록하지 않습니다.
- 근거 검토에서 거절되면 같은 공개 맥락으로 한 번만 다시 작성하고 다시 검토합니다. 거절된 원문은 재전송하거나 공개하지 않습니다. 제한 시간과 회수 내에서 실패하면 계획을 보존하고 재답변 버튼을 제공합니다.
- 서버도 페이지별 제안 종류를 검증합니다. 자산 상담은 사용자가 선택한 현금 비중을 바꾸지 못합니다. 조건 상담에서 자산 구성을 자동 변경하지 않습니다.

리스크 조건은 승인 전 알림 계획이며 자동 손절 주문이 아닙니다. 투자 시작 후 조건 충족 시 시장 정지 → AI와 논의 → 사용자 매매 승인 순서를 유지합니다. 주문은 판단 이후 다음 일봉 시가에 체결하며 서버 시계·Decimal 장부·이자는 유지합니다.

## 검증

`scripts/conversation_smoke.cjs`는 세 상담의 제안 거절·선택, 미선택 상태에서 다음 페이지 차단, 선택한 내용 전달, 원가 대비 손실 10%의 짧은 후속 답변, 조건 거절 후 8% 제안 선택, 복원·모바일, 최종 승인과 실제 체결·조건 감지를 검증합니다. 기본은 명시적인 UI 픽스처이며 `ERU_REQUIRE_AI=1`은 운영 환경의 실제 AI 응답을 요구합니다. 원시 대화와 세션은 `test-results/`에만 저장합니다.

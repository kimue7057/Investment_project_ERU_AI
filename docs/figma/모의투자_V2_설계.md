## 사용자 흐름

가상 현금 1억 원을 받고 종목 A~D를 탐색합니다. 차트에서 종목을 확인하고 금액 또는 보유 수량으로 주문합니다. 초기 비중 입력은 없습니다.

매수는 `금액 입력 → 수수료·총 필요 금액 확인 → 주문 접수 → 체결 대기 → 시장 재개 → 다음 일봉 시가 체결 → 보유 수량·현금 반영`을 구분합니다. 대기 중에는 현금 잔고와 주문 예약 금액, 추가 주문 가능 금액을 각각 표시합니다.

매도는 원하는 수량을 직접 입력하거나 25%·50%·전량을 선택합니다. 이는 사용자가 선택하는 일반 주문 수량이며 AI 제안 수정 기능이 아닙니다. 체결 후 실제 받은 금액과 남은 보유 수량을 함께 보여줍니다.

시안의 매수 예시는 매수대금 10,000,000원, 수수료 5,000원, 총 필요 금액 10,005,000원입니다. 구현 시 기존 수수료 포함 예산 API에는 총 필요 금액을 전달해야 합니다. 현재 서버 장부·체결 규칙을 이 문서 작업에서 변경하지 않았습니다.

## 제외한 기능

- 주식 E/F·부동산 G 및 준비 중 카드
- 초기 자산 비중 배분·리밸런싱 화면
- 새 투자 자료 공개·자료 공개 알림
- 리스크 신호 감지·AI 제안 수용·제안 비율 수정
- 시스템 자동 일시정지

사용자가 직접 누르는 일시정지·시장 재개는 유지했습니다. 기간 2022-11-07~2026-08-05, 재생 300초, 다음 일봉 시가 체결도 유지합니다. 실제 식별자·원문 URL·미래 이벤트·미확정 일봉을 종료 전에 노출하지 않는 조건을 계속 적용합니다.

## 검토 상태

주요 주문 흐름을 클릭으로 연결한 고정 예시 프로토타입입니다. 실제 시세 재생·금액 입력·검색·잔고 계산을 실행하는 앱이 아닙니다. 화면의 모든 가격·차트·수량·수익은 디자인 예시이며, 게임 데이터에 넣지 않았습니다.

12개 화면을 렌더링해 검토하고 안내문 잘림·행 정렬·색상·모바일 간격을 수정했습니다. 편집 가능한 레이어, Noto Sans KR 폰트, 제거 대상 문구 부재와 컨테이너 넘침 여부를 확인했습니다. 앱 코드를 변경하지 않아 이번 작업에서는 런타임 테스트·빌드·재배포를 수행하지 않았습니다.

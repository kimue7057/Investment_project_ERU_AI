기준 토큰은 배경 #0a101b, 탐색 #0d1828, 패널 #121e30, 보조 패널 #1a2940, 경계 #2a3c55, 본문 #edf5ff, 보조 #91a2bc, 강조 #38deba, 파랑 #7597ff입니다. React 공통 버튼·패널·레이아웃·자료 컴포넌트로 재구성했습니다. 원본의 점 SVG는 로컬 assets에 저장했습니다. 임시 Figma URL은 런타임에서 사용하지 않습니다.

원본의 가상 가격·수익률·샘플 차트는 실제 결과처럼 복제하지 않았습니다. 시작 화면에는 초기 자산과 플레이 절차를 표시하고, 실제 게임 차트는 서버의 완료 일봉으로 생성합니다. 화면의 약 4년 문구는 정확한 지정 날짜와 300초로 바꿨습니다. E/F/G는 후보를 거래 상품으로 확정하지 않고 준비 중으로 표시합니다. 현재 보유량은 Alpha 범위인 현금과 코인 4종을 모두 표시합니다.

390px 모바일 배치를 추가했습니다. 차트 공급자 표시를 유지하며 콘텐츠가 많은 화면과 모달은 세로 스크롤을 허용합니다. 디자인과의 비교는 test-results의 데스크톱/모바일 스크린샷으로 검증합니다.

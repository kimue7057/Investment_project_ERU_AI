# 가명과 종목별 거래·손익

## 표시 이름

사용자 화면은 새벽코인·물결코인·산들코인·노을코인을 사용합니다. 기존 내부 키 A/B/C/D, 시세 파일, 주문 대상, 저장 세션은 유지합니다. 새로운 실제 식별자를 공개하거나 E/F/G를 확정하지 않았습니다. 초기 설정·차트·주문·가드·판단·AI 대화와 종료 후 공개의 왼쪽 이름을 같은 가명으로 표시합니다. 기존 대화와 판단 원문은 저장소에서 변경하지 않고 공개 표시에서만 가명을 적용합니다.

## 자산 살펴보기

종목 탭마다 현재 수량, 평균 매수단가, 남은 원가, 평가액, 평가손익, 누적 매도 실현손익과 종목 총손익을 표시합니다. 이어지는 거래 내역에서는 실제 체결 날짜·시각, 매수/매도, 수량, 체결가, 거래금액, 수수료, 지급액/수령액, 배분된 원가, 해당 매도의 실현손익·수익률, 거래 후 보유 수량과 누적 실현손익을 확인합니다. 전체/매수/매도 필터와 거래가 없는 종목의 빈 화면을 제공합니다.

매수에서는 손익이 확정되지 않았다고 표시합니다. 보유 중 변동은 평가손익이며 예상 매도 수수료 차감 전입니다. 매도 후 원가를 모두 회수했거나 전량 매도했어도 이전 기록과 누적 실현손익은 남습니다. 게임 종료 후에도 자산 살펴보기를 열 수 있습니다.

## 계산과 호환

기존 체결 기록의 순서를 그대로 읽어 서버 Decimal로 원가를 복원합니다. 거래 전표에는 다음만 사용합니다.

- 매수원가 = 거래금액 + 매수 수수료
- 매도 수량의 원가 = 매도 직전 남은 원가 × 매도 수량 ÷ 보유 수량
- 매도 실수령액 = 거래금액 − 매도 수수료
- 해당 매도 실현손익 = 실수령액 − 배분된 매수원가
- 해당 매도 수익률 = 실현손익 ÷ 배분된 매수원가 × 100
- 종목 총손익 = 누적 매도 실현손익 + 현재 평가손익. 현금 이자 제외.

엔진의 이동평균 원가 배분과 같은 Decimal 연산 순서를 사용합니다. 기존 세션을 읽을 때 계산하므로 DB 마이그레이션이나 기존 체결 기록 덮어쓰기가 없습니다. 체결 전 대기 주문과 취소 주문은 체결 내역에 추가하지 않습니다. 매매·시계·수수료·이자 계산 경로는 변경하지 않았습니다.

새 공개 응답은 원본 전표를 복사하지 않고 at/asset/side/quantity/price/gross/fee/reason을 허용하고, 계산한 명세와 종목별 요약만 추가합니다. 실제 식별자·원문 URL·미래 이벤트·미확정 일봉은 전송하지 않습니다.

## 검증

`tests/test_trade_history.py`에서 부분 매도의 이익과 손실, 양방향 수수료, 이동평균 원가, 다종목 분리, 전량 매도 후 재매수, 과거 형식 세션, 기존 실제 시세 장부 대조, 읽기 불변성과 허용 필드를 검증합니다. 브라우저는 `scripts/history_smoke.cjs`로 실제 초기 매수·일부 매도·다른 종목 매수 후 화면 금액 대조·필터·재접속·320/390px를 확인합니다. `scripts/history_restore_smoke.cjs`는 실제 저장한 기존 세션을 복구해 종료 후 종목 화면과 폴링 중 유지도 확인합니다.

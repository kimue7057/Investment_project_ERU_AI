# 투자 종료 후 복기

[운영 앱](https://eru-ai-investment-simulator.vercel.app)에서 활성 재생 300초가 끝나면 **투자 복기**가 열립니다. 상단·모바일의 투자 복기, 자산, 판단 기록 메뉴로 이동할 수 있습니다.

## 화면

- 최종 자산과 수익률, 매매 순손익, 현금 이자, 이미 반영한 수수료, 최대 낙폭을 확인합니다. 매매 순손익은 실현손익과 남은 자산의 평가손익을 합한 값입니다. 이자를 더하면 시작 자산 대비 총손익이 됩니다. 수수료를 다시 차감하지 않습니다.
- 실제 총자산과 **처음 계획 그대로 보유**한 가정을 함께 그립니다. 날짜 슬라이더로 관측값을 확인합니다. 번호 또는 선택 카드를 누르면 해당 판단의 상황·구성·대화·체결·손익으로 이동합니다. 밀집된 번호는 연결선을 사용해 겹침을 피합니다.
- 유지 선택도 기록합니다. 당시 판단부터 다음 판단 또는 종료까지의 자산 변화는 전체 포트폴리오의 변화로 표시하며, 특정 선택만의 이익이라고 설명하지 않습니다.
- 체결 상세에는 가격·수량·거래금액·수수료·현금 흐름·평균 매수원가·실현손익을 표시합니다. 매수 시 손익은 미확정이며 종목별 보유분의 평가손익을 함께 봅니다.
- 종목별 누적 실현손익과 남은 보유분 평가손익, 처음·마지막 비중을 확인합니다. 실제 자산명은 종료 후 별도 버튼으로 확인합니다.

## 비교 계산

### 처음 계획 그대로 보유

첫 승인 비중을 같은 검증 시세의 다음 일봉 시가에 매수하고, 이후 추가 주문 없이 종료까지 보유합니다. 기존 엔진과 같은 Decimal 장부, 수수료, 금리 변경·예약금 제외·세전 단리 규칙을 사용합니다. 실제 첫 주문을 취소했더라도 이 비교는 첫 계획을 실행한 가정입니다. 초기 계획이 없는 이전 세션은 비교선을 제공하지 않습니다.

### 이 매매를 하지 않았다면?

연결된 체결 묶음 직전의 실제 현금·수량을 복원하고 다음 두 경우를 비교합니다.

1. 해당 매매를 실행하고 이후 추가 매매 없이 종료까지 보유.
2. 해당 매매를 생략하고 이후 추가 매매 없이 종료까지 보유.

각 경우는 체결 후의 현금과 코인 수량을 종료 가격으로 평가하고, 체결 이후 현금 이자를 더합니다. 매매한 경우의 수수료를 현금 흐름에 반영합니다. 체결 전 적립 이자는 양쪽에 공통이므로 제외합니다. 실제 이후의 주문을 그대로 재현하는 비교가 아닙니다. 이 가정의 자산 금액은 실제 최종 자산과 별개입니다.

매도 실현손익은 이동평균 매수원가 기준의 실제 확정 손익입니다. 가정 비교 차액은 매매 여부에 따른 이후 보유 결과의 차이이며 서로 다른 지표입니다. **선택별 비교 차액은 합산하지 않습니다.** 유지에는 가상의 대체 주문을 만들지 않으며, 첫 매수는 처음 계획 보유 비교로 확인합니다.

## 기록과 공개 경계

새 승인에는 안정적인 판단 ID, 당시 NAV·현금·이자·수량, 주문 요청, 아직 연결하지 않은 대화 ID를 저장합니다. 실제 다음 일봉 체결이 발생할 때 판단 ID를 연결합니다. 하나의 비중 조정에서 발생한 여러 매도·매수는 같은 판단에 연결합니다. 취소한 승인에는 취소 상태를 남깁니다.

이전 게임의 가격·장부를 변경하지 않습니다. 승인 연결 ID가 없는 이전 기록은 판단과 체결을 별도로 표시하고, 관련 대화나 당시 잔고를 추측하지 않습니다. 체결 묶음은 기록된 현금 흐름·수량으로 복원할 수 있을 때만 비교합니다.

`GET /api/sessions/{sid}/review`와 `POST /api/sessions/{sid}/review/recap`은 종료한 guided 세션에서만 허용합니다. 준비·진행·정지 상태에서는 400을 반환합니다. 복기는 서버에서 실제 검증 시세와 장부를 읽어 계산하며 브라우저의 가격·시계·잔고를 받지 않습니다. 일반 진행 응답에는 새 내부 스냅샷·주문 원문·대화 연결 목록을 보내지 않습니다. 체결과 복기는 허용 필드를 명시합니다.

복기 조회는 장부를 수정하지 않습니다. AI 복기 메타데이터만 별도로 세션 JSON에 저장하며 기존 Supabase CAS 저장을 사용합니다. 이메일 인증 도입 이후에는 해당 계정 소유의 게임만 열 수 있고, **내 투자 기록 → 결과 복기 보기**로 다시 확인합니다. 예전 비회원 원본 세션은 삭제하지 않으며 자동으로 계정에 귀속하지 않습니다. [계정별 보관](이메일인증과_계정보관.md)

## AI 복기

기존 `OPENROUTER_API_KEY`와 `OPENROUTER_MODEL`을 사용합니다. 서버가 계산한 사실과 성찰 질문의 ID 중 모델이 중요한 항목을 선택합니다. 허용 목록 밖의 ID와 자유 생성 숫자·추측한 투자 의도는 공개하지 않습니다. 화면에 **기록 선택형 복기**라고 표시합니다.

완료한 AI 복기는 저장해 재사용합니다. 실패 시 이유와 함께 기록 기반 복기를 제공하고 게임당 최대 3회까지 다시 요청할 수 있습니다. 중복 생성 요청은 차단합니다. 실제 매매와 장부는 변경하지 않습니다.

- `frontend/src/reviewModel.test.ts`: 날짜별 관측, 일정 자산의 차트 범위, 밀집 마커의 충돌 방지를 확인합니다.
- `scripts/review_smoke.cjs`: 인증 도입 전 실제 300초 운영 게임의 복기를 검증한 스크립트로 보존합니다. 현행 계정 기반 복기 진입·보관·두 계정 격리 검증은 `scripts/account_smoke.cjs`를 사용합니다.
- 원시 결과·로컬 검증 세션·스크린샷은 무시된 `test-results/`에만 저장합니다. 시세·세션 DB·키를 커밋하지 않습니다.
